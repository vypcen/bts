# Изменения TestBall QA

Версии нумеруются по [SemVer](https://semver.org/lang/ru/): `МАЖОРНАЯ.МИНОРНАЯ.ПАТЧ`.

- **Патч** (1.1.0 → 1.1.1) — исправления. Обновляться можно сразу, схема базы не меняется или меняется только добавлением.
- **Минорная** (1.1 → 1.2) — новые возможности. Миграции только добавляют таблицы и колонки; API `/api/v1` обратно совместим.
- **Мажорная** (1.x → 2.0) — несовместимые изменения. Что сделать до обновления, написано в разделе версии.

Перескакивать через версии можно: миграции всех промежуточных версий применятся по порядку. Как обновляться — [docs/UPGRADE.md](docs/UPGRADE.md).

## [1.1.0] — не выпущена

### Новое

- **Тест-кейсы:** структурные шаги с ожидаемым результатом у каждого шага, теги, пользовательские поля (текст, число, список, дата, флажок, пользователь) у кейсов, багов и прогонов.
- **Прогоны:** результат и фактический результат по каждому шагу, вложения к шагу.
- **Отчёты** по прогону и тест-плану в PDF и Excel.
- **Автотесты:** приём `allure-results` (повторы, flaky, параметры, шаги, вложения), связь автотеста с кейсом по метке.
- **Публичный API:** токены с правами `results` / `read` / `write`, сроком действия и лимитом запросов; префикс версии `/api/v1`.
- **Поиск** по кейсам, багам и прогонам (Ctrl+K), фильтры и постраничная выдача на сервере.
- **Журнал аудита** с выгрузкой в CSV; **корзина** для кейсов, прогонов и багов; удалённые проекты хранятся 30 дней и восстанавливаются.
- **Администрирование:** страница «О системе» (версия, сборка, база, история обновлений).

### Изменено

- `GET /api/state` возвращает только список проектов и пользователей; данные проекта — `GET /api/projects/:key/state`. Кейсы в нём без текста шагов, полный кейс — `GET /api/projects/:key/cases/:num`. Скриптам, читавшим `/api/state` целиком, нужно перейти на новые запросы (docs/API.md).
- Живые обновления приходят только по проектам, к которым у пользователя есть доступ.
- Удаление проекта — только администратор, с вводом ключа проекта.
- Токены, созданные до 1.1.0, получают право `results`: работают как раньше.

### Производительность

- Проект на 50 000 кейсов и 1 000 000 результатов: открытие ~1,3 с, поиск ~5 мс, аналитика ~0,8 с (docs/PERFORMANCE.md).

### Обновление с 1.0.x

Миграции 012–018 применятся автоматически при запуске. На большой базе (сотни тысяч результатов) первый запуск займёт несколько минут: строятся поисковые индексы. Сделайте резервную копию перед обновлением.

## [1.0.0] — 2026-11-14

Первая версия: проекты, тест-кейсы с папками и версиями, чек-листы, тест-планы, ручные прогоны, баги, автотесты (Playwright, JUnit XML), интеграции с трекерами и CI, вебхуки, аналитика, роли, единый вход (OIDC, LDAP, Kerberos), языковая модель, Docker Compose и Helm.
